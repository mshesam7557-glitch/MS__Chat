# MS__Chat Web v4

این نسخه فقط رابط موبایل را زیر 760px تغییر می‌دهد و CSS/رفتار دسکتاپ را دست‌نخورده نگه می‌دارد.

- موبایل: لیست گفتگو تمام‌صفحه + ورود تمام‌صفحه به چت + دکمه بازگشت
- دسکتاپ: چیدمان قبلی حفظ می‌شود
- WebRTC: خطایابی مرحله‌ای، درخواست رسانه مقاوم‌تر، ICE gathering، STUN/TURN normalization
- server.py: تنظیم امن TURN_URLS برای string یا list

فقط index.html و server.py را در مخزن Render جایگزین کنید. فایل .env را دست نزنید.
